# lite3_debug Artifacts

This directory stores debug outputs generated by train/play/deploy parity workflows.

## Main Paths
- `deploy/`: Deploy-side step dumps (`debug_cpp_step*.txt`).
- `train/<run_id>/`: Training play dumps (`debug_play_step*.npz`) for default reset semantics.
- `train_unrealistic/<run_id>/`: Training play dumps for legacy debug mode (`LITE3_UNREALISTIC_HISTORY_FEED=1`).
- `layer_compare*`: Layer-level PT vs ONNX comparison reports.
- `compare_report*.json`: Stage-level deploy vs training comparison reports.

## Notes
- These files are generated artifacts, not source code.
- Keep reports tied to the run ID used in the experiment.
- Remove stale artifacts before measurement-sensitive parity runs.
